3. How Developer Penetration Tests Were Executed

Test 1: Sensitive File Shield Attack Simulation

Attempted direct HTTP GET request to secret environment variables:

curl.exe -I https://whatsapp-reminder-0yad.onrender.com/.env

Observed Result: HTTP/1.1 403 Forbidden | Payload: {"error":"Access denied"}

Test 2: Brute-Force Rate Limiting Attack Simulation

Dispatched rapid burst of 6 invalid login requests within 10 seconds:

for ($i=1; $i -le 6; $i++) { Invoke-RestMethod -Method POST -Uri ".../api/auth/login" -Body $badPayload }

Observed Result: Requests 1 to 5 returned 401 Unauthorized. Request 6 immediately triggered 429 Too Many Requests with message: "Too many login attempts. Please wait 1 minute before trying again."

Test 3: Cross-Site Scripting (XSS) Filter Verification

Inserted malicious script payload into reminder title:

Title: <script>alert(document.cookie)</script>

Observed Result: Sanitized by escapeHtml() to &lt;script&gt;..., preventing JavaScript evaluation in DOM.
